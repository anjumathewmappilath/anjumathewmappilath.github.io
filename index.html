Things I've built

A few projects, told as short stories: the problem, what I did, what changed.

Project 1

Elevate learner journey

Elevate courses were all set up differently, and learners joined live classes without preparing. I helped define one standard journey, from onboarding to certification, and made pre-requisites a must before live classes. Course consumption [numbers on hold until Anju confirms].

Project 2

Live class quality audit

We had never counted quality problems in live classes, and ratings hid them. We built an audit that logged punctuality, faculty identity and student drop-off. The first report found 321 breaches in a day; then we cut them in half. Read the story.

Project 3

Placement data visibility

Every team was measured on placement rate, but the system could not compute it. I moved the placement journey out of Google Sheets and into the product. Now there is one source of truth: 1,960 learners in the placement pool, 3,834 applications, 415 placements. Read the story.
